Speak Any Language.
Get Clean Translations Instantly.

JoyVoice is an open-source Windows floating microphone dictation app. Press F8, speak in any of 10 languages (Bangla, Hindi, Russian, Arabic, etc.), and clean translated text appears directly wherever your cursor is in ~3.3 seconds.

🌐

10-Language Dictation

Speak Bangla, English, Russian, Hindi, Spanish, Arabic, Chinese, Japanese, French, or Portuguese with instant auto-language detection.

🧠

Gemini Native Audio

Uses Gemini 3.1 Flash Lite native audio understanding to transcribe and translate in a single API call (~3.0s wall-clock time).

🪟

Glass-Morphism Pill

Sleek 200×80px translucent floating microphone widget with live 5-bar waveform pulse and state animations.

📋

Clipboard-Safe Paste

Saves your clipboard, sends Ctrl+V with exponential backoff retry, and restores original clipboard contents intact.

⚡

Zero GPU Overhead

Pure cloud pipeline running on integrated graphics. No heavy local model downloads, no VRAM consumption.

🛡️

Built-in Fallback Chain

Automatic failover to free Google Web Speech API if the primary audio API is temporarily offline.

⚡ Run Directly From Local Folder

If you have cloned or downloaded this repository:

cd joyvoice
.venv\Scripts\activate
set JV_API_KEY=your_api_key
run.bat

Or download the prebuilt JoyVoice.exe (v2.3.2) for zero-config Windows launch.
