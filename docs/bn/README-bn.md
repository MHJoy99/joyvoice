## 1. JoyVoice কী করে?

**JoyVoice** হলো উইন্ডোজের জন্য একটি ভাসমান মাইক্রোফোন অ্যাপ (ফ্লোটিং মাইক উইজেট)। গ্লোবাল হটকি চাপুন, মুখে বলুন, আর পরিষ্কার অনুবাদ করা লেখা স্বয়ংক্রিয়ভাবে পেস্ট হয়ে যাবে — যেই অ্যাপে আপনার কার্সর আছে (Word, Chrome, Slack, Notion, VS Code — যেকোনো জায়গায়)।

**সহজ উদাহরণ:**

```text
আপনি বললেন (বাংলায়):  "আমি কাল সকালে মিটিং-এ যোগ দিতে পারবো না"
পেস্ট হলো (ইংরেজিতে):   "I won't be able to join the meeting tomorrow morning."
```

**ভেতরে যা ঘটে (সংক্ষেপে):**

1. 🎙️ **মাইক** — ১৬ kHz মোনোতে আপনার কথা রেকর্ড হয়।
2. 🧠 **স্পিচ টু টেক্সট (ASR)** — ডিফল্টভাবে Google Web Speech API দিয়ে কথা লেখায় রূপ নেয়।
3. ✨ **অনুবাদ ও পরিষ্কার** — Gemini টেক্সট মডেল অনুবাদ করে, দাঁড়ি-কমা ঠিক করে, হোঁচট-ফিলার শব্দ বাদ দেয়।
4. 📋 **নিরাপদ পেস্ট** — `Ctrl+V` দিয়ে লেখা বসিয়ে দেয়। আপনার আগের ক্লিপবোর্ড মুছে যায় না — আগে সেভ করে, পরে ফিরিয়ে দেয়।
5. 💾 **হিস্টরি গ্যারান্টি** — পেস্ট ব্যর্থ হলেও লেখা হারায় না। পেস্টের **আগেই** হিস্টরিতে সেভ থাকে।

> **মূল কথা:** কোনো উইন্ডো বদলানো লাগে না। কপি-পেস্ট লাগে না। ভাষা বাছাই করতেও হয় না (অটো-ডিটেক্ট আছে)। শুধু বলুন, লেখা চলে আসবে।

**দুইটি ইঞ্জিন মোড:**

| মোড | কী লাগে | কাদের জন্য |
| :--- | :------- | :---------- |
| **Cloud (ডিফল্ট)** | API কী (`JV_API_KEY` বা Settings → API-তে বসানো) | সবচেয়ে নির্ভুল ফলাফল, ১০ ভাষায় অনুবাদ, AI স্টাইল চান যারা |
| **Free ও Offline** | কোনো API কী লাগে না, লোকাল Whisper মডেল | ইন্টারনেট ছাড়া / খরচ ছাড়া চালাতে চাইলে। Settings → Free Mode থেকে একবার মডেল ডাউনলোড করলেই হয়। বাংলা → ইংরেজি অফলাইনেই হয়। |

## 2. ইনস্টল — venv, pip, run.bat

> শুধু **Windows 10 / 11 (64-bit)**-এ চলে। Python **3.11** লাগবে।

### যা যা লাগবে

| জিনিস | বিবরণ |
| :---- | :---- |
| Windows | 10 বা 11 |
| Python | **3.11.x** — `python --version` দিয়ে দেখে নিন |
| Git | রিপো ক্লোন করার জন্য |
| মাইক্রোফোন | ল্যাপটপের বিল্ট-ইন মাইক, হেডসেট বা USB মাইক — যেকোনোটা |
| API কী | Cloud মোডের জন্য `JV_API_KEY`। Free মোডে লাগে না। |
| জায়গা | প্রায় ৫০০ MB (ভার্চুয়াল এনভায়রনমেন্ট + ডিপেন্ডেন্সি) |

### ধাপ ১ — রিপো ক্লোন করুন

```cmd
git clone https://github.com/MHJoy99/joyvoice.git
cd joyvoice
```

> এর পরের সব কমান্ড `joyvoice/` ফোল্ডারের ভেতর থেকে চালাবেন।

### ধাপ ২ — ভার্চুয়াল এনভায়রনমেন্ট (venv) বানান

```cmd
python -m venv .venv
```

চাইলে অ্যাক্টিভেট করতে পারেন (বাধ্যতামূলক না — `run.bat` নিজেই venv-এর Python ব্যবহার করে):

```cmd
.venv\Scripts\activate
```

### ধাপ ৩ — পিপ (pip) দিয়ে ডিপেন্ডেন্সি ইনস্টল করুন

```cmd
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

> **টিপ:** কম্পিউটারে অন্য Python টুল (Anaconda, অন্য AI টুলচেইন) থাকলে `PYTHONPATH` জটিলতা হতে পারে। তখন এই নিরাপদ কমান্ডটি ব্যবহার করুন:
>
> ```cmd
> env -u PYTHONPATH -u PYTHONHOME .venv/Scripts/python.exe -m pip install -r requirements.txt
> ```
>
> ইনস্টল হয়েছে কি না দেখুন:
>
> ```cmd
> .venv\Scripts\python.exe -I -c "import sounddevice, numpy, speech_recognition, pyperclip, keyboard, typing_extensions; print('সব ঠিক আছে')"
> ```

মূল প্যাকেজগুলো: `PySide6` (উইজেট UI), `sounddevice` (মাইক), `numpy` (অডিও হিসাব), `pyperclip` (ক্লিপবোর্ড), `keyboard` (হটকি), `SpeechRecognition` (Google ASR), `typing_extensions` (ASR-এর জন্য আবশ্যক)।

### ধাপ ৪ — API কী বসান (Cloud মোডের জন্য)

**সহজ উপায় — Settings থেকে (রিকমেন্ডেড):**

অ্যাপ চালু করে উইজেটে রাইট-ক্লিক → **Settings → API** ট্যাবে API কী বসিয়ে Save করুন। কীটি আপনার কম্পিউটারেই থাকে (`%APPDATA%\JoyVoice\settings.json`-এ)।

**অথবা এনভায়রনমেন্ট ভেরিয়েবল দিয়ে:**

```cmd
:: Command Prompt (শুধু এই উইন্ডোর জন্য):
set JV_API_KEY=YOUR_KEY_HERE

:: PowerShell (শুধু এই সেশনের জন্য):
$env:JV_API_KEY = "YOUR_KEY_HERE"
```

স্থায়ীভাবে রাখতে চাইলে: `Win + R` → `sysdm.cpl` → Advanced → Environment Variables → User variables-এ `New` → নাম `JV_API_KEY`, মান আপনার কী → OK। তারপর টার্মিনাল নতুন করে খুলুন।

> Free ও Offline মোডে কোনো API কী লাগে না। Settings → Free Mode → **Set up Free Mode** চাপুন (প্রথমবার ইন্টারনেট লাগে), তারপর পুরো অফলাইনে চলবে।

### ধাপ ৫ — run.bat দিয়ে চালু করুন

সবচেয়ে সহজ নিয়ম — ফোল্ডারে **`run.bat`-এ ডাবল-ক্লিক** করুন। কালো কনসোল উইন্ডোসহ অ্যাপ চালু হবে, কোনো ভুল হলে সেখানেই দেখা যাবে।

```text
📁 joyvoice/
   ├── run.bat   ← এটাতে ডাবল-ক্লিক
```

অথবা কমান্ড লাইন থেকে:

```cmd
.venv\Scripts\python app\main.py
```

> ⚠️ ডিবাগ করার সময় `pythonw.exe` দিয়ে চালাবেন না — ভুল হলে কোনো মেসেজ দেখা যায় না। প্রতিদিন ব্যবহারে ঠিকঠাক চলছে নিশ্চিত হওয়ার পরেই `pythonw.exe` বা ডেস্কটপ শর্টকাট ব্যবহার করুন।
>
> প্রতিদিন এক ক্লিকে চালাতে চাইলে: `run.bat`-এ রাইট-ক্লিক → **Send to → Desktop (create shortcut)** → শর্টকাটের নাম দিন `JoyVoice`।

### চালু হয়েছে কি না যাচাই

1. স্ক্রিনে কালো কাচের মতো ভাসমান পিল (🎤 বোতামসহ) দেখা যাবে — সবসময় উপরে থাকে, ফোকাস কাড়ে না।
2. টাস্কবারের ডান পাশে সিস্টেম ট্রেতে JoyVoice আইকন আসবে।
3. ভাষা বাংলা থাকলে উইজেটে ছোট ব্যাজ দেখাবে: **`BN → EN`**।

## 3. F8 দিয়ে ব্যবহার — প্রতিদিনের নিয়ম

### মূল নিয়ম (টগল মোড, ডিফল্ট)

| কাজ | কী করবেন | উইজেটে যা দেখবেন |
| :--- | :-------- | :---------------- |
| **রেকর্ড শুরু** | **`F8` চাপুন** (অথবা 🎤 বোতামে ক্লিক) | কমলা রঙ + "Recording…" + নাচতে থাকা ৫টি ওয়েভফর্ম বার + টাইমার |
| **বলুন** | বাংলায় স্বাভাবিকভাবে বলুন। উদাহরণ: *"আমি কাল সকালে মিটিং-এ যোগ দিতে পারবো না"* | বারগুলো আপনার গলার আওয়াজ অনুযায়ী ওঠানামা করে |
| **রেকর্ড শেষ + পেস্ট** | আবার **`F8` চাপুন** | নীল "Transcribing…" → সবুজ "Pasted" + কার্সরের কাছে টোস্টে ফলাফল + হালকা বিপ সাউন্ড |
| **ফলাফল** | কার্সর যেখানে ছিল, লেখা সেখানেই বসে যায় | উইজেটে প্রথম ৫০ অক্ষরের প্রিভিউ (২ সেকেন্ড থাকে) |

> রেকর্ডিং-এর সময়সীমা সর্বোচ্চ ৫ মিনিট। ভুল করে রেকর্ড চালু রেখে চলে গেলেও মেমোরি ফুল হবে না।

### আরও দুইটি শর্টকাট

- **ভাষা বদলানো:** `Ctrl+Shift+L` — Settings না খুলেই সোর্স ও টার্গেট ভাষা বদলানোর ছোট পপআপ আসে উইজেটের পাশে। Apply দিলেই সেভ হয়।
- **হোল্ড মোড (ঐচ্ছিক):** Settings → Hotkey-তে `hotkey_mode` = `hold` করলে চেপে ধরে রেকর্ড, ছেড়ে দিলে প্রসেস। ডিফল্ট `toggle`-ই বেশিরভাগের জন্য সুবিধাজনক।

### উইজেটের রঙের মানে

| রঙ | অবস্থা | মানে |
| :--- | :----- | :--- |
| ধূসর | Idle | প্রস্তুত, অপেক্ষা করছে |
| কমলা | Recording | রেকর্ড হচ্ছে, কথা বলুন |
| নীল | Transcribing | API-তে পাঠানো হয়েছে, অপেক্ষা করুন |
| সবুজ | Pasted | সফল! ১.২ সেকেন্ড থাকে |
| লাল | Error | সমস্যা হয়েছে, ৩ সেকেন্ডে নিজে নিজে ঠিক অবস্থায় ফেরে |

নিচে ৩ পিক্সেলের **কনফিডেন্স বার** থাকে — সবুজ মানে ভালো ফলাফল, হলুদ মানে মাঝারি, লাল মানে খুব ছোট/খালি ফলাফল।

## 4. সমর্থিত ১০টি ভাষা

সোর্স (আপনি যা বলবেন) ও টার্গেট (যে ভাষায় অনুবাদ চান) — দুই দিকেই এই ১০টি ভাষা চলে। **Auto Detect** রাখলে ভাষা বাছাই করতেই হয় না — মাঝপথে বাংলা থেকে ইংরেজিতে গেলেও JoyVoice ধরে ফেলে।

| কোড | ভাষা | নেটিভ নাম | Google ট্যাগ | অটো-ডিটেক্ট | অনুবাদ টার্গেট |
| :--: | :---- | :--------- | :----------- | :----------: | :------------: |
| `auto` | অটো ডিটেক্ট | 🔍 | — | ✅ | — |
| `bn` | বাংলা | বাংলা | `bn-BD` | ✅ | ✅ |
| `en` | ইংরেজি | English | `en-US` | ✅ | ✅ |
| `ru` | রুশ | Русский | `ru-RU` | ✅ | ✅ |
| `hi` | হিন্দি | हिन्दी | `hi-IN` | ✅ | ✅ |
| `es` | স্প্যানিশ | Español | `es-ES` | ✅ | ✅ |
| `ar` | আরবি | العربية | `ar-SA` | ✅ | ✅ |
| `zh` | চীনা (ম্যান্ডারিন) | 中文 | `zh-CN` | ✅ | ✅ |
| `ja` | জাপানি | 日本語 | `ja-JP` | ✅ | ✅ |
| `fr` | ফরাসি | Français | `fr-FR` | ✅ | ✅ |
| `pt` | পর্তুগিজ | Português | `pt-BR` | ✅ | ✅ |

> ⚠️ মনে রাখুন: সেটিংসে ভাষার কোড সবসময় ছোট কোডে লিখুন — `bn`, `en` এইভাবে। `bn-BD` লিখবেন না। `bn-BD` ট্যাগটি অ্যাপ নিজে ASR-কে ডাকার সময় ভেতরে ভেতরে ব্যবহার করে।

## 5. সেটিংস — সোর্স, টার্গেট, আউটপুট মোড

খুলবেন যেভাবে: **উইজেটে রাইট-ক্লিক → Settings** (অথবা ট্রে আইকনে রাইট-ক্লিক)।

সব সেটিংস থাকে এখানে: `%APPDATA%\JoyVoice\settings.json` — সাধারণ JSON ফাইল, চাইলে হাতে এডিটও করা যায়।

### আউটপুট (সবচেয়ে জরুরি ট্যাব)

| সেটিং | কী | ডিফল্ট | বুঝিয়ে |
| :---- | :-- | :------ | :------ |
| **Source language** (`language`) | আপনি কোন ভাষায় বলবেন | `bn` | `auto` রাখলে স্বয়ংক্রিয় শনাক্ত। নির্দিষ্ট রাখতে চাইলে `bn` / `en` / `hi` ইত্যাদি। |
| **Target language** (`target_language`) | কোন ভাষায় অনুবাদ চান | `en` | ১০টির যেকোনোটি হতে পারে। বাংলায় ফেরত চাইলে `bn` করুন। |
| **Output mode** (`output_mode`) | কী পেস্ট হবে | `translation` | `original` = শুধু যা বললেন (বাংলা), `translation` = শুধু অনুবাদ (ইংরেজি), `both` = দুইটাই (মাঝে ফাঁকা লাইন দিয়ে)। |
| **Text style** (`text_style`) | লেখার সাজ | `clean_english` | নিচে দেখুন। |

**টেক্সট স্টাইল ৫টি:**

| স্টাইল | কী করে | ইন্টারনেট/API লাগে? |
| :----- | :------ | :------------------: |
| `raw` | যেমন শোনা গেল, তেমন — কোনো পরিষ্কার না | না |
| `clean_english` | ফিলার ("আমম", "মানে") বাদ, হোঁচট ঠিক, বানান-রিপ্লেসমেন্ট, দাঁড়ি-কমা ও ক্যাপিটালাইজেশন | না |
| `prompt_for_ai` | AI-কে দেওয়ার মতো গোছানো প্রম্পটে সাজায় | হ্যাঁ (Cloud) |
| `professional_message` | ভদ্র, প্রফেশনাল ইমেইল/মেসেজের সুরে লেখে | হ্যাঁ (Cloud) |
| `facebook_post` | ক্যাজুয়াল, সোশ্যাল পোস্টের ঢঙে লেখে | হ্যাঁ (Cloud) |

> Free ও Offline মোডে AI স্টাইল চলে না — পরিষ্কার করা লেখাই পেস্ট হয়, আর টোস্টে জানিয়ে দেয়।

**উদাহরণ:** সোর্স `bn`, টার্গেট `en`:

- `translation` → `I won't be able to join the meeting tomorrow morning.`
- `original` → `আমি কাল সকালে মিটিং-এ যোগ দিতে পারবো না`
- `both` → উপরের দুই লাইন, মাঝে একটি ফাঁকা লাইন।

### হটকি ট্যাব

| সেটিং | ডিফল্ট | অপশন |
| :---- | :------ | :---- |
| Hotkey (`hotkey`) | `F8` | `F8`, `Ctrl+Alt+Space`, `Ctrl+Space` বা নিজের মতো কাস্টম |
| Hotkey mode (`hotkey_mode`) | `toggle` | `toggle` (চাপ = শুরু, আবার চাপ = শেষ) / `hold` (চেপে ধরে রেকর্ড, ছাড়লে শেষ) |

### অডিও ট্যাব

- **Microphone** (`audio_device_name`) — খালি থাকলে সিস্টেম ডিফল্ট মাইক। চাইলে নির্দিষ্ট মাইক বেছে দিন।
- **Call muting** (`mute_other_apps`) — রেকর্ডের সময় কল অ্যাপ (Discord/Zoom/Teams) মিউট রাখতে চাইলে: `off` / `hotkey` / `virtual_device`। `hotkey` মোডে সংশ্লিষ্ট অ্যাপে গ্লোবাল মিউট শর্টকাট আগে থেকে সেট করা থাকতে হয়।

### পেস্ট ট্যাব

| সেটিং | ডিফল্ট | মানে |
| :---- | :------ | :--- |
| Paste mode (`paste_mode`) | `paste` | `paste` = স্বয়ংক্রিয় `Ctrl+V`, `copy_only` = শুধু ক্লিপবোর্ডে রাখবে, আপনি নিজে পেস্ট করবেন |
| Paste delay (`paste_delay_ms`) | `300` | পেস্টের আগে অপেক্ষা (মিলিসেকেন্ডে)। ধীর অ্যাপে (ব্রাউজার/Electron) বাড়িয়ে ৭০০/১০০০ করুন। |
| Restore clipboard (`restore_clipboard`) | চালু | পেস্টের পর আগের ক্লিপবোর্ড ফিরিয়ে দেয় — পাসওয়ার্ড ম্যানেজারের জন্য নিরাপদ |
| Wait for hotkey release (`wait_for_hotkey_release`) | চালু | হটকির বোতাম পুরো ছাড়ার পর পেস্ট করে — আটকে যাওয়া Ctrl সমস্যা হয় না |

### রিপ্লেসমেন্টস ট্যাব

নিজের শব্দ-প্রতিস্থাপন নিয়ম (word-boundary, case-insensitive)। ডিফল্ট কয়েকটি:

| যা শোনে | যা লেখে |
| :------- | :------- |
| `bdx tree` | BDX |
| `bdx market` | BDX Market |
| `mh joy gamers hub` | MHJoyGamersHub |
| `sellar` | seller |
| `giftcard` | gift card |
| `one crore` | 1 crore |

নিজের ব্র্যান্ড/নাম/পদবি এখানে যোগ করে রাখলে প্রতিবার ঠিক বানান পাবেন।

### API ও Free Mode ট্যাব

- **API ট্যাব:** Base URL (ডিফল্ট `https://gpt.bdx.market/v1`), API কী, অডিও মডেল (`joyvoice-fast-audio`), টেক্সট মডেল (`gemini-3.6-flash`)। **Fetch models** দিয়ে লাইভ মডেল তালিকা আনা যায়, **Test connection** দিয়ে সংযোগ যাচাই করা যায়।
- **Free Mode ট্যাব:** ইঞ্জিন `cloud` / `free`, স্পিচ মডেল Tiny / Base / **Small (ডিফল্ট)**, ডিভাইস Auto / CPU, অনুবাদ Auto / Whisper / None। **Set up Free Mode** = মডেল একবার ডাউনলোড, **Test** = মডেল লোড করে পরীক্ষা।

## 6. ডায়াগনস্টিকস এক্সপোর্ট — সমস্যা হলে যা পাঠাবেন

কিছু না চললে আন্দাজে মেসেজ না দিয়ে এই প্যাকেজটি পাঠালে সমাধান দ্রুত হয়।

### ডায়াগনস্টিকস উইন্ডো খোলা

**উইজেটে রাইট-ক্লিক → Diagnostics...** (অথবা ট্রে মেনু থেকে)।

সেখানে পাবেন:

- মাইক/ডিভাইস ও সংযোগের স্বাস্থ্য-সারাংশ
- লগের শেষ অংশ (শেষ কয়েকশো লাইন)
- **Copy** বোতাম — সারাংশ ক্লিপবোর্ডে কপি হয়
- **Export bundle (.zip)** বোতাম — পুরো ডায়াগনস্টিক প্যাকেজ সেভ হয়

### এক্সপোর্ট বান্ডেলে যা থাকে

`.zip` ফাইলের ভেতরে (নাম যেমন `joyvoice-diagnostics-2026-...zip`):

- `joyvoice.log` (+ রোটেটেড পুরোনো লগ যদি থাকে)
- `usage.jsonl` (ব্যবহার-পরিসংখ্যান, যদি থাকে)
- স্যানিটাইজড সেটিংস (API কী **বাদ দিয়ে** — গোপন তথ্য যায় না)
- ভার্সন তথ্য

> 🔒 **নিরাপদ:** এক্সপোর্টে আপনার API কী পাঠানো হয় না। তবু জিপ খুলে একবার চোখ বুলিয়ে নিতে পারেন।

### হাতে লগ/সেটিংস দেখা

| ফাইল | পথ |
| :--- | :-- |
| লগ | `%APPDATA%\JoyVoice\joyvoice.log` |
| সেটিংস | `%APPDATA%\JoyVoice\settings.json` |
| হিস্টরি | `%APPDATA%\JoyVoice\history.json` |

এক্সপ্লোরারের অ্যাড্রেস বারে `%APPDATA%\JoyVoice` লিখে Enter দিলেই ফোল্ডার খুলবে।

### রিপোর্ট করার সময় যা যা দেবেন

1. কী করছিলেন (যেমন: "F8 চেপে বাংলা বললাম, দ্বিতীয় F8-এর পর নীল হয়ে আটকে থাকলো")
2. ডায়াগনস্টিকস `.zip` ফাইলটি
3. Windows ভার্সন + মাইকের নাম + `run.bat`-এর কনসোলে দেখা এরর (যদি থাকে)

পাঠানোর জায়গা: [GitHub Issues](https://github.com/MHJoy99/joyvoice/issues) — নতুন Issue খুলে জিপটি অ্যাটাচ করুন।

## 7. সাধারণ প্রশ্ন — FAQ

### প্রশ্ন ১: F8 চাপলে কিছুই হয় না কেন?

**উত্তর:** তিনটি কারণ সবচেয়ে বেশি দেখা যায় —

1. অন্য কোনো অ্যাপ F8 দখল করে রেখেছে (বিশেষ করে গেম ওভারলে/রেকর্ডার)। Settings → Hotkey থেকে `Ctrl+Alt+Space` করে দেখুন।
2. অ্যাপ অ্যাডমিন/স্লিপ/UAC-এর পর হটকি হারিয়েছে — JoyVoice প্রতি ৫ সেকেন্ডে নিজে নিজে হটকি ফিরিয়ে আনে। ১০ সেকেন্ড অপেক্ষা করে আবার চাপুন, না হলে অ্যাপ রিস্টার্ট করুন।
3. `run.bat` দিয়ে চালু করেননি — প্রথমবার সবসময় `run.bat`-এ ডাবল-ক্লিক করে চালু করুন, কনসোলে এরর দেখা যাবে।

### প্রশ্ন ২: বাংলা বললাম, কিন্তু ভুল/আধা-ভাঙা ইংরেজি এলো কেন?

**উত্তর:** প্রথমে মাইক ও পরিবেশ দেখুন — ফ্যান/এসির শব্দ, অনেক দূরের মাইক, বা ভাঙা USB মাইকে নির্ভুলতা কমে। তারপর দেখুন: সোর্স ভাষা `bn` বা `auto`-তে আছে কি না, টার্গেট `en`-এ আছে কি না, আউটপুট মোড `translation`-এ আছে কি না। Cloud মোডে নেট ধীর হলেও ফলাফল দেরিতে/অসম্পূর্ণ আসতে পারে। Free মোডে থাকলে Tiny থেকে **Small** মডেলে যান — বাংলা অনেক পরিষ্কার হবে।

### প্রশ্ন ৩: API কী ছাড়া কি JoyVoice চলবে? খরচ কত?

**উত্তর:** হ্যাঁ, চলবে। Settings → Free Mode → Engine = **Free & Offline** করুন, **Set up Free Mode** চাপুন (প্রথমবার একবার ইন্টারনেট লাগে মডেল ডাউনলোডে), তারপর পুরো অফলাইন — কোনো কী, কোনো খরচ নেই। Cloud মোডে খরচ গেটওয়ে-ভেদে কলপ্রতি খুব সামান্য (প্রায় $0.001-এর ঘরে), মডেল ও রেকর্ডিং-এর দৈর্ঘ্য অনুযায়ী বদলায়। সঠিক দাম আপনার API প্রোভাইডারের পেজে দেখুন।

### প্রশ্ন ৪: পেস্ট হচ্ছে না / আগের কপি করা লেখা হারিয়ে যাবে কি?

**উত্তর:** না, হারাবে না। JoyVoice পেস্টের আগে আপনার ক্লিপবোর্ড সেভ করে রাখে, পেস্টের (~১.৫ সেকেন্ড) পর আগেরটা ফিরিয়ে দেয়। পেস্ট না হলে: (১) Paste ট্যাবে `paste_delay_ms` বাড়িয়ে ৭০০ করুন, (২) `paste_mode` সাময়িকভাবে `copy_only` করে হাতে `Ctrl+V` দিন, (৩) টার্গেট অ্যাপে ফোকাস (কার্সর) ঠিক জায়গায় আছে কি না দেখুন। মনে রাখুন — লেখা পেস্টের **আগেই** হিস্টরিতে সেভ থাকে, তাই উইজেটে রাইট-ক্লিক → শেষ ৫টি থেকে আবার কপি করতে পারবেন।

### প্রশ্ন ৫: মিটিং/কলে কথা বলার সময় JoyVoice চালালে অপর পাশে আমার কথা/বিপ শোনা যাবে?

**উত্তর:** যেতে পারে — কারণ মাইক তখন দুই দিকেই খোলা। সমাধান: Settings → Audio → **Call muting** চালু করুন। `hotkey` মোডে Discord/Zoom/Teams-এর গ্লোবাল মিউট শর্টকাট আগে থেকে সেই অ্যাপের সেটিংসে সেট করে রাখতে হয়। সবচেয়ে নির্ভরযোগ্য উপায় `virtual_device` মোড (VB-Cable/VoiceMeeter থাকলে) — রেকর্ডের সময় ভার্চুয়াল ডিভাইস মিউট হয়ে থাকে। রেকর্ড শেষে স্বয়ংক্রিয়ভাবে আনমিউট হয়।
